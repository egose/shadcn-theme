# Form Checkbox (`@egose/shadcn-theme-ng/form-checkbox`)

A ready-made reactive-form checkbox row: `hlm-checkbox` + label + required marker with automatic `hlm-error` / `hlm-hint` display, wrapped in `eg-form-field` error switching. Equivalent to shadcn/ui `Form` + `Checkbox` composition.

The Angular implementation is a standalone `ControlValueAccessor`-compatible wrapper (not a brain
primitive itself): it renders `HlmCheckbox` bound with `formControlName`, `HlmLabel`, `EgFormField`
from `@egose/shadcn-theme-ng/form-field-simple`, and `HlmError` / `HlmHint` from
`@egose/shadcn-theme-ng/form-field`. It must live inside a `FormGroupDirective` (a
`[formGroup]` parent) and forwards `ControlContainer` to it. Ids are generated by
`HlmFormIdGenerator` unless overridden.

> **Ships as:** `@egose/shadcn-theme-ng/form-checkbox` and `@egose/shadcn-theme-ng-tw/form-checkbox`
> (the `tw:`-prefixed Tailwind variant). Both expose the identical TypeScript surface; only the
> emitted Tailwind class strings differ. See the [package README](../../README.md) for install
> steps, peer dependencies, and Tailwind setup. Do not publish this project directory independently.

## Installation

```bash
# Plain Tailwind (no prefix)
npm install @egose/shadcn-theme-ng

# tw:-prefixed Tailwind variant
npm install @egose/shadcn-theme-ng-tw
```

Peer dependencies (Angular, `@spartan-ng/brain`, `@ng-icons/*`, `rxjs`, …) are documented in the
[package README](../../README.md#peer-dependencies). This subpath additionally relies at runtime on
`@egose/shadcn-theme-ng/checkbox`, `@egose/shadcn-theme-ng/label`,
`@egose/shadcn-theme-ng/form-field`, and `@egose/shadcn-theme-ng/form-field-simple`.

## Imports

Exported from the subpath root (`projects/form-checkbox/src/public-api.ts`). Note: this subpath
exports a single standalone component — there is no `*Imports` array or `*Module`:

```ts
import { EgFormCheckbox } from '@egose/shadcn-theme-ng/form-checkbox';
// tw variant: replace with '@egose/shadcn-theme-ng-tw/form-checkbox'
```

Standalone usage:

```ts
import { Component } from '@angular/core';
import { ReactiveFormsModule } from '@angular/forms';
import { EgFormCheckbox } from '@egose/shadcn-theme-ng/form-checkbox';

@Component({
  selector: 'app-demo',
  standalone: true,
  imports: [ReactiveFormsModule, EgFormCheckbox],
  template: `...`,
})
export class DemoComponent {}
```

NgModule-based consumer: add `EgFormCheckbox` (and `ReactiveFormsModule`) to the module's `imports`
— it is a standalone component, not a module.

`ControlValueAccessor` behavior: `eg-form-checkbox` itself is not a `ControlValueAccessor`; the
inner `hlm-checkbox` is bound via `[formControlName]="controlName()"`, so the parent `FormGroup`
owns the value. `checked()` sets the initial checkbox input; the form control is the source of
truth afterwards.

## Anatomy / Structure

```html
<form [formGroup]="form">
  <eg-form-checkbox
    controlName="acceptTerms"
    label="Accept terms and conditions"
    [required]="true"
    hint="You must accept to continue."
    error="You must accept the terms."
  />
</form>
```

Selector (from source): `eg-form-checkbox` (standalone component).

## API reference

### `EgFormCheckbox` — `eg-form-checkbox`

| Input           | Type                  | Default | Description                                                                                 |
| --------------- | --------------------- | ------- | ------------------------------------------------------------------------------------------- |
| `controlName`   | `string`              | `''`    | `formControlName` key inside the parent `FormGroup`. **Required.**                          |
| `label`         | `string`              | `''`    | Label text next to the checkbox.                                                            |
| `error`         | `string \| undefined` | —       | Error text shown when the control is invalid + touched/dirty (via `EgFormField` switching). |
| `hint`          | `string \| undefined` | —       | Hint text shown when there is no error to display.                                          |
| `controlId`     | `string \| undefined` | —       | Explicit control id (first priority for `effectiveId`).                                     |
| `id`            | `string \| undefined` | —       | Fallback id (second priority).                                                              |
| `name`          | `string \| undefined` | —       | Checkbox `name` attribute (defaults to `controlName`).                                      |
| `checked`       | `boolean`             | `false` | Initial checked state passed to `hlm-checkbox`.                                             |
| `required`      | `boolean`             | `false` | Shows a red `*` and sets checkbox `required`.                                               |
| `disabled`      | `boolean`             | `false` | Locks interaction via checkbox `wrapperDisabled` (does not write to the form control).      |
| `class`         | `ClassValue`          | `''`    | Extra host classes.                                                                         |
| `checkboxClass` | `string`              | `''`    | Extra classes for `hlm-checkbox`.                                                           |
| `labelClass`    | `string`              | `''`    | Extra classes for the label.                                                                |
| `$errorClass`   | `string`              | `''`    | Extra classes for `hlm-error`. (Note the `$` prefix — part of the real input name.)         |
| `$hintClass`    | `string`              | `''`    | Extra classes for `hlm-hint`. (Note the `$` prefix.)                                        |

| Member               | Description                                                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `effectiveId`        | `controlId() \|\| id() \|\| generated` — wired to checkbox `id` and label `for`.                                                     |
| `errorId` / `hintId` | `effectiveId + '-error' / '-hint'` for `aria-describedby`.                                                                           |
| `describedBy()`      | Returns `errorId` when `error()` is set and the control is invalid + dirty/touched, else `hintId` when `hint()` is set, else `null`. |

Requires a `[formGroup]` ancestor: the component injects `FormGroupDirective` and provides
`ControlContainer → FormGroupDirective` so `formControlName` resolves.

## Examples

### 1. Basic required terms checkbox

```ts
import { Component, inject } from '@angular/core';
import { FormBuilder, ReactiveFormsModule, Validators } from '@angular/forms';
import { EgFormCheckbox } from '@egose/shadcn-theme-ng/form-checkbox';

@Component({
  selector: 'app-terms',
  standalone: true,
  imports: [ReactiveFormsModule, EgFormCheckbox],
  template: `
    <form [formGroup]="form" (ngSubmit)="submit()">
      <eg-form-checkbox
        controlName="accept"
        label="Accept terms and conditions"
        [required]="true"
        error="You must accept the terms."
      />
      <button type="submit" [disabled]="form.invalid">Continue</button>
    </form>
  `,
})
export class TermsComponent {
  private readonly fb = inject(FormBuilder);
  readonly form = this.fb.group({ accept: [false, Validators.requiredTrue] });
  submit() {
    console.log(this.form.value);
  }
}
```

> `disabled` locks the UI via `wrapperDisabled` without disabling the form control itself, so the
> value still submits. To exclude the value, call `form.get('readonly')?.disable()` instead.

### 6. Submitted-state validation (mark all touched)

```ts
import { Component, inject } from '@angular/core';
import { FormBuilder, ReactiveFormsModule, Validators } from '@angular/forms';
import { EgFormCheckbox } from '@egose/shadcn-theme-ng/form-checkbox';

@Component({
  selector: 'app-submit-check',
  standalone: true,
  imports: [ReactiveFormsModule, EgFormCheckbox],
  template: `
    <form [formGroup]="form" (ngSubmit)="submit()">
      <eg-form-checkbox
        controlName="consent"
        label="I consent to data processing"
        [required]="true"
        error="Consent is required to create your account."
      />
      <button type="submit">Create account</button>
    </form>
  `,
})
export class SubmitCheckComponent {
  private readonly fb = inject(FormBuilder);
  readonly form = this.fb.group({ consent: [false, Validators.requiredTrue] });
  submit() {
    this.form.markAllAsTouched();
    if (this.form.valid) console.log('creating account…');
  }
}
```

## Accessibility notes

- The checkbox `id` and label `for` are generated (`eg-form-checkbox-<app>-<n>`) unless `controlId`/`id` is given — labels are always programmatically associated.
- `aria-describedby` points at the error id only while the control is invalid + touched/dirty, otherwise at the hint id — screen readers hear the right message in each state.
- The required marker (`*`) is visual; the underlying `hlm-checkbox` also receives `required` so assistive tech announces it.
- Keep the component inside a `<form>` with a submit path; the row itself is a single tab stop (the checkbox).

## Theming / CSS variables

No component-specific CSS variables. Style via `class`, `checkboxClass`, `labelClass`, `$errorClass`, `$hintClass` inputs and global tokens. The row layout (`flex items-center gap-1`) is fixed in the template.
